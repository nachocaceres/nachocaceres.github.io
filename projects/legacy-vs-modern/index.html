What actually changed under the hood

SQL built with string concatenation Parameterized queries via Dapper
Whole DataTable loaded into memory, paged in code SQL Server OFFSET/FETCH — the database pages, not the app
Full-page postback on every sort, page or search JSON REST API, client-side state, no page reload
No automated tests 24 passing xUnit tests covering the API
Session-based auth tied to IIS Stateless JWT auth
Business rules duplicated across code-behind files Centralized in a repository layer, unit-testable
