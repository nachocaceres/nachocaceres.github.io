About

For the past 4 years I've worked as a developer at a financial institution, building and maintaining mission-critical systems: online banking (ASP.NET Web Forms, VB.NET, C#), WCF service layers, and SQL Server databases handling live financial data.

Most developers run from legacy code. I don't — these are the systems that actually run businesses, and working at a bank taught me to change them carefully: test thoroughly, understand the blast radius of every change, and never break production. I bring that same discipline to every project, whether I'm fixing a 2,000-line stored procedure with no documentation or migrating a Web Forms app to a modern .NET 10 + React stack.
